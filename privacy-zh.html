隐私政策

生效日期 // 2026年10月5日 // 最后更新：2026年10月5日 // 数据控制者：NeuroOrbit AI

本译本仅为方便阅读而提供。如本译本与英文版本有任何不一致之处，以英文版本为准。

Quiet Translator 是一款按“零留存”原则设计的应用程序。语音输入会被实时处理并显示在屏幕上——音频绝不会被录制、保存或存储在我们的服务器或您的设备上。

// 01

麦克风权限与音频数据

Quiet Translator 需要访问您设备的麦克风，其唯一目的是在会话进行期间提供实时语音翻译。

您的音频将通过加密连接（HTTPS/WSS）以流式方式传输至第 06 条所列的语音识别服务提供商，并由其实时转写为文字。

我们不会保存、录制或存储任何音频文件——无论是在您的设备上还是在我们的服务器上。音频以实时流方式传输，并在处理完成后立即丢弃。服务器端音频保留期限：0 天。

语音识别和翻译服务提供商可能为提供服务而对音频进行临时处理。我们无法控制其内部处理流程，建议您查阅其隐私政策。在有相应选项可供选择的情况下，我们会选择在处理完成后不留存音频用于模型训练的服务提供商。

// 02

不存储转写文本

翻译后的文本仅在您的会话进行期间显示于屏幕上。会话结束后，我们不会将转写文本存储于任何数据库、日志或文件中。

服务器端转写文本保留期限：0 天。设备端转写文本保留期限：0 天。

// 03

我们收集的数据

账户数据

  • 电子邮箱地址（通过 Firebase Authentication 获取）
  • 一个假名化的用户标识符
  • 如果您使用 Google 或 Apple 账号登录，我们会从上述服务提供商处获得基本的账户标识信息——我们不会获取或存储您的密码

使用数据

  • 已使用的收听时长（以分钟计）
  • 您当前的订阅方案及剩余分钟数
  • 所使用的语言组合（例如：英语 → 乌克兰语）
  • 应用版本及设备操作系统，用于故障诊断

设备标识符（防滥用）

为防止一次性免费试用被滥用，我们使用设备层面的信号：iOS 上为 Apple DeviceCheck，Android 上为 Android ID。该信号仅用于执行试用和使用限额，不用于广告，不与广告商共享，也不用于在其他应用或网站上追踪您。

订阅数据

由 Apple（App Store）、Google（Google Play）及我们的订阅管理服务提供商（RevenueCat）提供的您的订阅状态、订阅方案、购买及续订事件。我们不会获取或存储您完整的支付卡信息——付款由 Apple 或 Google 处理。

我们不会收集您的对话内容。

保留期限：账户数据和使用数据在您的账户有效期间予以保留，并在您最后一次活动后最长保留 24 个月，届时将被永久删除。您可以随时删除您的账户（见第 07 条）。

// 05

录制他人语音——由您负责

在某些地区，法律要求在采集或处理他人语音之前须征得其同意。您应负责确保在使用 Quiet Translator 时遵守您所在地的所有适用法律。

由于 Quiet Translator 不存储音频或转写文本，我们不会制作或留存任何他人的录音。

您的权利与账户删除

根据您所在的司法管辖区——包括依据 GDPR（欧盟《通用数据保护条例》）、UK GDPR（英国《通用数据保护条例》）、加拿大 PIPEDA（《个人信息保护和电子文件法》）以及 CCPA/CPRA（美国加利福尼亚州《消费者隐私法》及《隐私权法》）——您享有以下权利：

  • 查阅我们所持有的关于您的个人数据
  • 更正不准确的数据
  • 删除您的数据（被遗忘权）
  • 将您的数据转移至其他服务（可携带权）
  • 对基于正当利益的处理提出反对
  • 随时撤回同意，且不影响撤回前已依法进行的处理

账户删除。您可直接在应用内删除账户：设置 → 删除账户（Settings → Delete Account）。此操作将从我们的系统中删除您的账户及相关使用数据。订阅的取消需通过您的 Apple ID 设置（iOS）或 Google Play 账户设置（Android）进行管理。删除账户并不会取消仍然有效的订阅。

加利福尼亚州居民（CCPA/CPRA）：您有权了解我们收集哪些个人信息，有权要求删除该等信息，并有权选择拒绝个人信息的“出售”或“共享”。我们不会出售您的个人信息。

提出请求：mission@neuroorbitai.com——我们将在 30 天内予以答复（CCPA 请求为 45 天）。您也可以向当地的监管机构投诉，例如您所在欧盟成员国的数据保护机构（DPA）、英国信息专员办公室（ICO）、法国国家信息与自由委员会（CNIL）、加拿大隐私专员办公室（Office of the Privacy Commissioner of Canada）、魁北克信息获取委员会（Commission d'accès à l'information du Québec）或巴西国家数据保护局（ANPD）。

// 08

数据跨境传输

数据可能在位于美国及其他国家的服务器上进行处理。

欧盟/欧洲经济区及英国用户：数据传输依据欧盟委员会通过的标准合同条款（第 2021/914 号决定）进行。

// 09

数据安全

我们采取符合行业标准的安全措施，包括传输过程中的 TLS 加密、账户数据的静态加密、严格的访问控制以及定期的安全审查。

// 10

儿童隐私

Quiet Translator 并非面向未满 13 周岁（或您所在司法管辖区规定的最低年龄）的儿童。我们不会在知情的情况下收集儿童的个人数据。如果您认为有儿童向我们提供了数据，请与我们联系，我们将予以删除。

// 11

本政策的变更

如有任何重大变更，我们将至少在变更生效前 14 天通过电子邮件和/或应用内通知告知您。在生效日期之后继续使用本应用，即视为您接受更新后的政策。
